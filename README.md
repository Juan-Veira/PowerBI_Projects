# Data Jobs Power BI Dashboard Portfolio

This repository showcases a collection of Power BI dashboards that reflect my progression from foundational reports to more advanced, interactive analyses. Each project focuses on transforming raw data into clear, actionable insights.

The work in this portfolio was created following a course by **Luke Barousse** — big thanks to him for the clear explanations and great learning material that made this dashboard possible.

## About This Portfolio

Explore the dashboards below. Each project includes a dedicated README with details on the problem addressed, data preparation, key features, and the development process, along with insights into the data sources and Power BI techniques used.

## Data Jobs Dashboard V1

![Data Jobs Dashboard V1](Data_Jobs_Dashboard\Data_Jobs_Dashboard_V1\Images\V1_Dashboard_Overview.gif)

**View the dashboard here:** [Data Jobs Dashboard V1](Data_Jobs_Dashboard\Data_Jobs_Dashboard_V1\Data_Jobs_Dashboard_V1.pbix)

**Key Power Bl Skills Utilized:**

* **Power BI Fundamentals:** Building interactive dashboards and reports
* **Data Visualization:** Using bar, column, line, gauge, and treemap charts
* **KPI Design:** Creating indicators to highlight key metrics
* **Implicit Measures:** Applying built-in aggregations (avg, median, min, max)
* **Dashboard Design:** Structuring clean, user-friendly, and story-driven layouts
* **Interactivity:** Implementing slicers for dynamic filtering
* **Navigation Features:** Using buttons and bookmarks for smooth UX
* **Drill-Through Analysis:** Enabling deep dives from summary to detail views
